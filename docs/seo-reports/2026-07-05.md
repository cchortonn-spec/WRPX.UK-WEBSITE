## Top 5 Highest-Impact Fixes

### 1. No Yorkshire-wide subcontract aggregation hub (HIGH — being fixed this run)
**Impact:** Competitive positioning +2 pts. A user searching "subcontract vinyl installer Yorkshire" or "vinyl installation subcontractor South Yorkshire" has no single landing page that aggregates WRPX's full offer across all partner types (sign companies, print houses, agencies). Individual service pages exist but the top-of-funnel entry point is missing. Fix: `/subcontract-vinyl-installation-yorkshire/` being created this run.

### 2. No city-level subcontract pages for primary markets (HIGH — being fixed this run)
**Impact:** Local SEO +1 pt, Competitive positioning +1 pt. Sign companies and print houses in Sheffield and Doncaster searching for local installation subcontractors won't find a WRPX page targeting their city specifically. The existing `/commercial-installation-sheffield/` page targets general commercial, not the subcontract buyer specifically. Fix: `/subcontract-vinyl-installer-sheffield/` and `/subcontract-vinyl-installer-doncaster/` being created this run.

### 3. Aggregate rating on LocalBusiness schema is still placeholder (MEDIUM)
**Impact:** Structured data −2 pts. The `aggregateRating` in `/lib/schema.ts` uses `ratingValue: "5", reviewCount: "5"` which is a placeholder. This either needs verified Google review data or should be removed if unverified. Left as-is for now since removing requires a schema decision, but flagged for Connor to update with real review count when available.

### 4. B2B blog content is thin relative to commercial page count (MEDIUM)
**Impact:** Content quality +1 pt. Only one B2B blog post exists on main (`commercial-vinyl-installer-background-matters`). Adding one B2B educational post per week builds topical authority faster. Fix: `/blog/how-to-brief-an-installation-subcontractor/` being created this run.

### 5. Internal linking from homepage/nav to new B2B pages is sparse (MEDIUM)
**Impact:** On-page SEO, crawl depth. The main nav still leads primarily to kitchen-wrap services. The commercial-installation page links to sign company and vehicle-wrap partners, but the new subcontract hub isn't surfaced in primary navigation. Fix for next run: review nav to add a trade partner/subcontract CTA path.

## Competitor Research

### A. Subcontractor / Partner Keywords (Primary Focus)

Searched for: "vinyl installation subcontractor South Yorkshire", "sign company installation partner Yorkshire", "subcontract vinyl installer Sheffield", "commercial vinyl installer for print companies".

**Key findings:**
- **Sign Install (signinstall.co.uk, Kippax Leeds):** Explicitly targets M1/M62 white-label for sign manufacturers. Strong on "unbranded vans" and overflow capacity messaging. No dedicated page for marketing agencies. Coverage is national but South Yorkshire is in their core zone — direct competitor on sign company keywords.
- **DL Sign Installation (dlsigns.co.uk, Castleford WY):** Active on LinkedIn, credible Sheffield-Nottingham coverage. No dedicated location pages for city-level search. No blog/content. WRPX has structural advantage with location pages.
- **IPL Group (ipl.group, Leeds):** National scale, 80+ crews. Targets large brands, not SME sign companies or regional print houses. Irrelevant as a direct competitor for WRPX's B2B niche.
- **Local gap confirmed:** No South Yorkshire-based competitor has a page targeting "subcontract vinyl installer Yorkshire" as a primary keyword. WRPX can own this with the hub page being built today.

**What competitors do well that WRPX should match or beat:**
- Sign Install: "your brand, not ours" positioning is strong — WRPX has this but could make it more prominent on city-specific pages
- DL Signs: LinkedIn presence builds B2B credibility — not a website fix but noted for Connor

### B. Kitchen Wrapping (Monitoring — No New Pages This Run)

Existing rankings for Sheffield kitchen wrapping remain stable. No new competitors have appeared for core city pages. No clear gap that warrants a new kitchen-wrap page this run — existing coverage (7 cities) is adequate for now.

### C. Vehicle Wrap (Light Touch — No Action This Run)
